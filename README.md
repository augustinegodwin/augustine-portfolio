# Augustine Godwin — Portfolio (Section 1: Hero)

```bash
npm install
npm run dev
```

Everything editable (name, years of experience, links, projects) lives in `data/site.ts`.

- Add a real backdrop: put `hero.mp4` or `hero.jpg` in `/public` and set `heroMedia` in `data/site.ts`.
- Add project screenshots: put images in `/public/projects` and set `image` per project.
- Keyboard: `←` `→` change project, `H` opens Upwork.
